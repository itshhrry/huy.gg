Python Excel Power Query Real-World Data

Revenue Cycle Management — Practice Analytics

Analyzed real-world billing data from a multi-provider medical practice using Python, Excel, and Power Query. Built an interactive dashboard and comprehensive billing report to surface actionable insights across collections, denials, payer behavior, and provider performance.

Business questions

  • How are A/R loads and collection rates tracking month over month?
  • Which payers generate the highest write-off burden per encounter?
  • Where are denial rates concentrated — by provider, CPT, or payer?
  • How does reimbursement compare to allowed revenue across encounter types?

Approach

  • Cleaned and transformed raw billing data using Python and Power Query
  • Built univariate and multivariate analysis across payer and encounter dimensions
  • Designed an interactive Excel dashboard with slicers for payer, month, and provider
  • Produced a comprehensive billing report with provider-level KPIs

Key metrics

  • Net collection rate (NCR) — 84% overall
  • Denial rate — 61% with 39% pass rate
  • Allowed revenue — 56% of total billed
  • Average write-off per encounter by payer
  • Provider utilization and resolution rates

Outcome

Delivered a reporting suite that enables practice leadership to identify high-denial payers, track provider-level performance, and monitor reimbursement efficiency — supporting data-driven decisions in revenue cycle operations.

Python pandas NumPy Excel Power Query Data Modeling

Revenue Cycle Management Dashboard

Designed and generated a synthetic revenue cycle management dataset in Python using rule-based operational and financial logic, then built an Excel dashboard with Power Query and data modeling to analyze reimbursement performance, denials, efficiency, and profitability.

Objective

Evaluate how reimbursement behavior, denial patterns, and operational efficiency impact financial performance in a revenue cycle context.

Approach

  • Rule-based dataset design with realistic financial logic
  • MPRR reductions and standardized adjustment coding
  • Dictionary-driven RARC assignment
  • CPT dependency rules, including 96372 logic

Key metrics

  • Reimbursement totals and reimbursement rate
  • Denial volume and denial trends
  • Operational efficiency indicators
  • Profitability comparison

Outcome

Produced a reporting tool that enables comparison of performance drivers and demonstrates how reimbursement patterns, denials, and operational processes influence financial outcomes.

Self-Hosted Home Server Infrastructure
