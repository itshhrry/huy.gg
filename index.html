Excel Power Query Data Modeling

Revenue Cycle Management Dashboard

Built an Excel-based analytical dashboard using a fictitious revenue cycle management dataset to evaluate reimbursement performance, denial activity, operational efficiency, and profitability.

Objective

Analyze revenue cycle performance and compare the operational factors affecting financial outcomes.

Approach

Structured the dataset using a star-schema-style model and used Power Query to support cleaner reporting, dashboard design, and flexible analysis.

Key metrics

  • Reimbursement totals
  • Rate of reimbursement
  • Denials and denial trends
  • Operational efficiency
  • Profitability comparison

Outcome

Created a reporting tool designed to compare performance drivers and show how reimbursement behavior, denials, and operational efficiency can affect profitability.
