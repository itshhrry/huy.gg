Revenue Cycle Management Dashboard

Designed and generated a synthetic revenue cycle management dataset in Python using rule-based operational and financial logic, then built an Excel dashboard with Power Query and data modeling to analyze reimbursement performance, denials, efficiency, and profitability.

Objective

Evaluate how reimbursement behavior, denial patterns, and operational efficiency impact financial performance in a revenue cycle context.

Approach

Built a multi-table synthetic dataset in Python to model revenue cycle operations, then used Excel and Power Query to structure and analyze the data.

  • Rule-based dataset design with realistic financial logic
  • MPRR reductions and standardized adjustment coding
  • Dictionary-driven RARC assignment
  • CPT dependency rules, including 96372 logic

Key Metrics

  • Reimbursement totals and reimbursement rate
  • Denial volume and denial trends
  • Operational efficiency indicators
  • Profitability comparison

Outcome

Produced a reporting tool that enables comparison of performance drivers and demonstrates how reimbursement patterns, denials, and operational processes influence financial outcomes.
