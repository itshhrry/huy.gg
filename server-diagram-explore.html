Server diagram explorations

Five visual treatments for the self-hosted infrastructure card. Pick a winner and I'll drop it into projects.html.

Currently in use

Diagram

Cloudflare → GitHub Pages and home server, with the home server fanning out to four service nodes. Calm, accurate, matches the rest of the site. (See projects.html for the live version with full text labels and animation.)

↳ Already live on projects.html

Option 1

Isometric 3D rack

A stylized 3D server with rack units stacking up. Service chips float around it, connected by thin animated dashed lines. More illustrative, less diagrammatic.

Option 2

Topology rings

Concentric rings: edge (outermost) → host → services. Pulses radiate outward like a network monitor. Feels alive without being chart-y.

Option 3

Animated terminal

A fake docker ps session listing every running service. Plays into the engineer aesthetic, fun and self-aware. Different visual language than the rest of the site, though.
